# Oracle Power vs x86 kalkulator / calculator

Kalkulator Oracle licenci i TCO-a: IBM Power naspram x86. Srpski (`/`) i engleski (`/en/`).
Oracle licensing and TCO calculator: IBM Power versus x86. Serbian (`/`) and English (`/en/`).

Instalacija kao aplikacija (PWA): otvorite stranicu u Chrome-u ili Edge-u i kliknite ikonicu „Instaliraj“ u adresnoj traci.
Install as an app (PWA): open the page in Chrome or Edge and click the Install icon in the address bar.

Svi brojevi, faktori licenciranja i odnosi performansi su procene za sales pripremu; pre obavezujuće ponude potvrditi kod Oracle-a i IBM-a.
All figures, licensing factors and performance ratios are estimates for sales preparation; confirm with Oracle and IBM before a binding offer.

Ažuriranje: posle izmene fajlova povećajte `VERSION` u `sw.js`.
Updating: after changing files, bump `VERSION` in `sw.js`.
